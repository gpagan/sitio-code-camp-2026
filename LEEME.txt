No se publican en internet.


CÓMO ABRIR UN PROYECTO
----------------------
1. Instala Visual Studio Code y su extensión "Live Server".
2. En Visual Studio Code, abre la carpeta del proyecto (Archivo > Abrir carpeta).
3. Clic derecho en index.html > "Open with Live Server".
   Se abre en Chrome desde tu propia computadora (dirección 127.0.0.1).

Los proyectos P1 a P13 y los juegos también abren con doble clic en index.html.
P14, P15 y el juego de cierre necesitan Live Server para usar la cámara y leer el modelo.

Lo que cada estudiante puede cambiar está marcado en el código con la palabra PERSONALIZA.

EL MODELO DE IA (P13, P15 Y JUEGO DE CIERRE)
--------------------------------------------
1. En Teachable Machine, crea un proyecto de imagen con 4 clases escritas así:
   Piedra, Papel, Tijera y Nada.
2. Entrena el modelo y descárgalo: Export Model > Tensorflow.js > Download.
3. Descomprime el archivo. Copia la carpeta con model.json, metadata.json y
   weights.bin dentro de P15-control-gestos y de cierre/piedra-papel-tijera-ia,
   con el nombre "mi_modelo". (Ya hay una carpeta mi_modelo vacía con instrucciones.)
4. El modelo se queda en la computadora: no se sube ni se publica.
5. P15 y el juego de cierre necesitan internet para cargar las librerías de IA
   (TensorFlow.js y Teachable Machine, desde cdn.jsdelivr.net).
6. Si la cámara o internet fallan, el juego de cierre tiene botones de respaldo.
